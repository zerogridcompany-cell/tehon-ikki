## 0. 先に結論（効く 6 つ）
1. **大きな切り替えは全部「曲の裏拍（8 分音符の“&”）」に置く**：曲 M4GN「BRISA TE LEVAR (SLOWED)」117.5 BPM（拍 510ms・8 分 255ms）。色の切り替え 3 回が裏拍から −9／−19／+8ms、ブラー始め +14、メーター閃光 −31、0-100 の閃光山 −10、Ton essai 切り替え +14、ボタン爆発 +2、ロゴへ +12ms。**表拍には置かん**（表拍から 220〜260ms 後）。
2. **光は「閃光 1〜2 コマ（33〜66ms）で立ち上がり、100〜250ms で落ちる」を場面の継ぎ目に使う**（画面平均 L が 25→90〜123 まで 1〜3 コマ・落ちは 130〜250ms）。切り替えの継ぎ目を光が隠す。
3. **3 本の光の筋（シアン白・青・赤＝BMW M の 3 色）が時間差で入り、真ん中で出会い、3 つの弧にほどけ、閃光で輪＝ロゴになる**（ロゴ 1 つに 2.0 秒）。
4. **UI の切り替えは横ブラー（動きの向きに潰れる）＋出る側は ease-out**。ブラー 2 回：短 110ms と長 370ms。
5. **一つの入力を同じ札が持ち続ける**（導入のロゴ→窓→入力バーが「同じ形が姿を変える」）。終わりは頭と同じ BMW M のロゴ＝ループ（13.68→0.00）。
6. **字・数字は光で「温度」を持つ**：0-100 の 4,0 は橙赤（熱）で入り 200ms で白に冷める。

## 2. 技 8 つ

### 技① 光の筋 → リングのロゴ（Light streaks converge → ring flash logo）
- **コマ（始・山・止）**：シアン白の筋 入り 1.07／青の筋 1.20／赤の筋 1.40（差 130ms・200ms）→ 3 本が真ん中（x 0.5・y 0.4）で出会う 2.45–2.5 → 3 つの弧にほどけ 2.6–2.9 → 光が玉になる 3.00 → 閃光 3.033 始め・3.117 山（L 99）・3.15 保つ→ 輪が広がる 3.183–3.25 → 3.35 に落ち着く＝**始 1.07・山 3.117・止 3.35**。
- **筋の動き**（画面幅＝1 とした位置）：シアン白＝左端から x 0.01(1.07)→0.22(1.27)→0.35(1.40)→0.45(1.93)→0.50(2.40)＝**ease-out（最初 1.05 幅/秒・最後 0.15 幅/秒）**。青＝右上から x 0.98(1.20)→0.71(2.00)→0.54(2.40) y 0.11→0.34＝**ほぼ線形・終わりだけ速い（−0.33→−0.5 幅/秒）**。赤＝下から y 0.86(1.40)→0.75(1.80)→0.56(2.47)＝**線形（約 −0.26 幅/秒）**。→ 3 本の到着を同じ 2.45〜2.5 に揃える（速さを変えて到着を合わせる）。
- **ほどけ**：筋が弧（C 形）に曲がる 2.55–2.9（明るさ L 12→17）・3 つの弧は M の 3 色（淡青・青・赤）＝光の玉が膨らむ 2.9–3.0。
- **輪**：画面幅比の半径 r50（芯の半分の明るさ）＝0.10（3.033）→0.16（3.067）→0.22（3.10）→0.24（3.117）→0.32（3.217）＝**expo-out（67ms で 0.10→0.22）**。画面平均 L＝25→39→60→78→90→99（3.133）→95→84→77→59→40→33（3.35）。**立ち上がり 100ms・保ち 40ms・落ち 200ms**。輪の中心 (0.49, 0.43)・芯の M タイルは 3.117 で白く飛び（core 243）、3.183→3.317 で core 196→80 と落ちてタイルが見える。
- **色**（カメラ撮りの値＝実色より甘い）：筋の芯 #e7fbfb／青 #4f71cf／赤 #b02123／輪 #566ed1→#4474c3（外縁に紫がかった縁＝赤が混ざる）。設計の意図の色は BMW M 公式の 3 色（#81C4FF・#0066B1・#E7222E＝公式ブランド値・未承認・測ったのではない）。
- **光（芯＋裾）**：青い筋の頭で、芯 L253→ r 1.0%（幅比）で 50%→ r 4% で 23%→ r 9% で 9%→ r 13% で 5%＝**2 段の山（hikari.md の型）**＝芯は幅の 1%・裾は 4〜9%。地は #080611 付近→2.9 秒に #0f0d1a まで育つ（玉の周りの暖かい霞）。
- **音**（oto_ms）：2.8386・3.0327（peak 3.040）に弱い立ち上がり（強さ 0.09〜0.11）＝**3.0327 は閃光の始め（3.033）と同時（絵が 0〜17ms 遅れ＝音と絵は同時扱い）**。曲の 103 BPM の裏拍に筋の入りは置かれていない（1.07/1.20/1.40 は拍と無関係）＝**この場面は音に合わせず絵が先に走る**。閃光は音の山に合わせる。
- **Remotion**：`<LightStreaks streaks=[{color,from:'left'|'topright'|'bottom',tIn,tConverge,ease}] converge={[0.5,0.4]} />`（SVG の線＋`feGaussianBlur` 2 段＝芯 1%幅・裾 4〜9%幅・加算合成 `mix-blend-mode:screen`）／`<ArcSplit arcs=3 colors=[…] />`（stroke-dasharray で弧が曲がる）／`<RingFlash cx cy rise={100} hold={40} fall={200} r50={[.10,.24,.32]} />`（radial-gradient 2 段＋`tw(f,a,b,EASE.expo_out)`）。各筋の位置は keys.json の PCHIP（シアン＝expo-out・青＝linear・赤＝linear）。waza20 の W01_Particles・W04_Neon が土台。

### 技③ 色の丸で切り替え（color swatch → 車と札が替わる）
- **コマ（始・山・止）**（画面の車の面の平均色が変わる 1 コマ目＝始）：青→緑 **5.700 始・5.750 止（約 50〜66ms）**／緑→白 **6.183 始・6.250 止（67ms）**／白→赤 **6.717 始・6.800 止（83ms）**。間隔＝5.717→6.217→6.767＝**500ms・550ms（曲の 8 分音符 255ms の 2 つ分）**。各色の保ち＝約 0.45 秒。
- **切り替えの形**：ほぼハードカット（2〜3 コマ）。切り替えの瞬間に明るさの小さな山（緑の G が 82→106 に跳ねて 100ms で 88 に落ち着く＝**+25 の閃き・100ms で収まる**）。丸のカーソル（白い輪）が先に次の丸へ移る（f267＝カーソルが 2 つ目に乗る→車が替わる＝**カーソル先・車が約 50ms 後**）。
- **一緒に替わるもの**：①車 ②車の下の反射 ③右上の札（Bleu→Vert→Blanc→Rouge Toronto・字の長さが替わっても右寄せ）④左下の進み棒（60→75→68%）⑤丸の中の選択の輪。**1 つの state（色 index）から全部を引く**。
- **曲線**：車の入り（最初の青い車）だけ 5.22–5.62 の横滑り＋ブラー（技⑥）。以後の色替えは切り替えのみ（動かさん＝車の位置は同じ）。
- **音**：5.6675（peak 5.670・rise 2.7ms・str 0.09）＝青→緑の 5.70 の 30〜50ms 前／6.0688・6.1745（rise 0）＝緑→白（6.183）の 8ms 前／6.9803（peak 7.003）＝白→赤の後 200ms。**音（曲の打）が絵より約 10〜50ms 先**（oto 弱いので参考）。
- **Remotion**：`<ColorSwatchSwitch colors=[…] hold={[0.5,0.55,…]} cutFrames={2} flash={+25} />`・車は色別の画像 4 枚を `<Img>` で切る（実在の BMW の写真は使わん＝自社の別の商品に差し替える時は 4 色の商品画像）・`const idx = Math.floor(frameToIndex)` から札・進み棒・反射を全部引く。

### 技④ 計器の数字（Gauge/Counter：0-100 km/h 4,0 s の弧と数字）
- **コマ（始・山・止）**：青い地が点く 7.217（L 57）→ **7.250 閃光（L 116・1 コマ）**→ 7.38 に落ち L 25（130ms）→ 数字が回る 7.28–7.55（180→473→480 ch・**約 270ms で 0→480＝ease-out**）→ 7.52–7.65 上へ縦流れ（gx/gy 1.34＝縦ぼけ・差 14）→ 7.683 次の面の閃光が始まり **7.783 山（L 103）**→ 8.02 に落ちる。
- **数字の回り**：桁が上下に流れる（縦ぼけ・各桁が別の速さで止まる＝「1?0」「473」のように桁ごとに止まる）。止まる順＝右の桁が最後（480 の 0 が最後）。
- **4,0 s**：橙赤（目視で #ff6a3a 付近・色の測りは青い地を拾って失敗＝未測）で入り 7.78→8.0 の 220ms で白（#efeeed）へ冷める。上に 3 色の線（青・濃青・赤＝M のストライプ・幅 0.25 画面・位置は 4,0 の上 0.1）が引かれる。「0-100 km/h en」の字が 4,0 の上。
- **光**：青い面の radial（中心 (0.5,0.5)・青 #3877c0・外は #02010d）＝数字を囲む。7.78 の山で面が一番明るく、4,0 が冷める時に面が消えて黒地（#02010d）になる＝**光が消えて数字だけが残る**。
- **音**：7.2274（peak 7.278・rise 50ms・str 0.08）＝閃光 7.250 の 23ms 前に鳴り始め→**音が先**。7.6322（peak 7.655）＝縦に流れる所。曲の裏拍 7.281 に閃光（−31ms）。

### 技⑤ ドロップダウン（M2/M3/M4/M5 の選択メニュー）

### 技⑥ ブラーの切り替え（Directional blur transition）
- **2 回**：
  - **短** 3.65–3.75（差 17→23→15→8）：窓「Mon garage M」→「Quelle M tu veux ?」。**約 4 コマ（110ms）**・横ぼけ（gx/gy 0.67→0.39）・中身が左へ流れ右から次が入る。
  - **長** 5.217–5.62（差 9→16→23（5.383 山）→22→18→11→6→2＝**始 5.183・山 5.38〜5.45・止 5.65＝約 400ms**）：古い UI が左へ流れ、新しい UI（青い M2＋丸 4 つ）が**右から滑り込んで着地**。gx/gy（横の鋭さ÷縦の鋭さ）＝0.60 → 0.28（5.25〜5.45）→ 0.62（5.65）＝**ぼけが 5.25 から立ち上がり 5.45 まで最大・5.65 までに消える（立ち上がり 70ms・保ち 200ms・戻り 200ms）**。
  - 他：8.317 の 1 コマ切り替え（差 30＝ハードカット＋次の面に傾き）／12.98 の閃光ぼけ。
- **ぼけの長さ（概算）**：長い方は 1 コマ（33ms）で車が約 0.06〜0.10 幅動く＝**横ぼけ 100〜160px（1600 幅の 6〜10%）が最大**。測定ではなく「コマ間の移動量×シャッター」の概算（測れんかった物に記録）。
- **入りの曲線**：着地する UI は**expo-out（最初の 1 コマで 0.22 幅・5 コマで残り 10%）**。出る UI は ease-in（動き始めがゆっくり）。ブラーの量＝速さに比例（位置の変化に連動）。
