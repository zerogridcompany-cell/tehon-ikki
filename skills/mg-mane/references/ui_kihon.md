## 0. 5 つの決まり（ux_02〜06 の中身そのまま＝白 UI の作り方の核）
| # | 決まり | 悪い例 → 良い例（手本の数字） |
|---|---|---|
| 1 | **余白は等しくしない（階段にする）** | 全部 12px → **6（ラベル→入力）／16（欄と欄）／24（最後の欄→ボタン）**＝近い物は近く・区切りは広く。比 1 : 2.7 : 4 |
| 2 | **人の言葉で書く** | 「Basket」→「Add to Basket」／「Submit」→「Subscribe →」。説明書の言葉でなく人が話す言葉 |
| 3 | **情報を減らす** | 長い文章（Lorem 10 行）→ 見出し 1＋説明 1 行＋折りたたみ 3（Ingredients・How to use・Pro tip・各行に線画アイコン＋右に ⌄）＋ボタン |
| 4 | **ボタンは結果が分かる言葉** | Submit（何が起きる？）→ **Subscribe →**（行き先の矢印つき）。結果＋動詞 |
| 5 | **エラーはその場で** | 下の端に「Invalid phone number」→ **欄の真下に赤い縁＋右に ⓘ＋赤い警告文**。欄の縁が 1px の灰→1px の赤（#e5484d 付近）に変わる |
- 各枚の組み＝**左が悪い例（赤い丸 ×）・右が良い例（緑の丸 ✓）**。下に手書き風の短い注（左＝灰「Too much information.」・右＝紫「Clean, focused and easy to scan.」）＋曲がった矢印で札を指す。
- 1 枚＝1 つの決まり。**札の中身は左右で 1 点だけ違う**（比較の切り分け）。

## 2. 札の中の部品（ux_05・[測]）
- **紫のボタン**：[測] 幅 **約 500px（札の幅の 84%）・高さ 83px（札の 幅 14%）・完全な丸角（pill＝角 41px＝高さの半分）**・縦のグラデ **上 #856bf3 → 下 #6341ec（中央 #7258fb）**・上辺に細い内側のハイライト（白 alpha .35・1px）・字 白・中太 約 30px（Inter 系）・中央寄せ・字の左にアイコン（線画の籠）or 右に →。影＝**紫がかった下向きの影（0 10px 24px rgba(99,65,236,.35)）**。
- **入力欄**：[概] 高さ 約 76px・幅は札の内側いっぱい（札の左右 45px 内）・角 約 16px・面 白・縁 **1px #dcdce3**・左に線画アイコン（✉）・placeholder 灰 #8e8e96・字 約 26px。ラベル（「Your email」）は欄の上 約 14px・黒 #222・中太 約 24px。
- **札の内側の余白**：[概] 左右 **45px（札幅の 7.5%）**・上 約 50px・下 約 45px。要素の間は §0 #1 の階段（6/16/24 を ×3 した約 18/48/72px＝**手本の「px」表記は 1 枚の中の相対値で、1620 ページでは約 3 倍**）。
- **タイトル**（札の見出し）：[概] 中央寄せ・黒 #111・太字 約 36px（ux_05「Join the newsletter」）／本文 灰 #6f6f78・約 24px・行間 1.45・中央寄せ・幅は札の内側の 85%。
- **3D の絵**（封筒・ヘッドホン・ハンドクリーム）：丸みのある 3D（白〜薄灰＋紫の差し色）・下に柔らかい接地影・札の上半分・幅 約 35%。**写真は札の中に角 約 20px で入る**（ux_04 の写真＝札の幅 −2×40px・角 20px）。

## 3. 影・光（札を面でなく影で浮かせる）[測] ux_05 左の札
- 札の下端（y≈1706）の直下の輝度 213（背景 254＝暗さ −41 ≒ 16%）→ **約 150px かけて 254 へ**（10px 刻み：213・220・225・231・234・238・240・243・247・248・249・251・252・254）＝**下方向の影が長い**。左の端は 232→254 を約 60px・札の上の端は 217→245 を約 25px ＝**影は下に偏る（y 方向 +45px 前後）**。
- → CSS の目安（1620 幅）：`box-shadow: 0 45px 100px -10px rgba(50,40,110,.20), 0 6px 20px rgba(50,40,110,.08)`（1080 幅なら ×0.667）。**2 枚重ね＝遠い大きな影＋近い小さな影**（手本の断面が 2 段の減り方＝速く 25px・ゆっくり 150px）。縁取りの線は無し（面と背景が同じ白）。
- 丸の印の光は §1。ボタンの影は §2。**白 UI で黒い影を使わず、青紫がかった影（hue 250〜260°・彩度 低）にする**＝紙っぽい冷たさでなく「清潔」。
- 背景（ページ）＝**純白でなく #fefefe・上から下へごく弱い灰（0.5%）**。札の周りに紫の淡い霞（半径 札の幅 80%・alpha .04）を敷く投稿もある（ux_03 の右の札の背後）。
