## 0. 先に結論（効く 5 つ）
1. **UI を「光の線で描いて」出す**：黒地に青いネオンの縦線 1 本→線が角を曲がって窓の枠になり、中の UI が点く（0.0〜2.3 秒）

## 2. 技（名前つき）
### 技① Light-drawn UI（光の線が UI の枠を描く）
- コマ：線が立つ 0.0→角を曲がる 0.8→窓の枠が閉じる 1.5→中の UI が点く 2.0（始 0.0・山 1.5・止 2.3）
- 光＝芯（白に近い青）＋裾（#0d3393→#061350）の 2 段（hikari.md の型）。窓の枠の線は太さ 3〜4px・裾は幅の約 4%
- Remotion：SVG の path（枠の形）に `stroke-dasharray/offset` を ease-out で 0→1、`feGaussianBlur` 2 段（σ 2・σ 18）を `mix-blend-mode:screen` で重ねる。中の UI は線が閉じた後 opacity 0→1（300ms）
### 技② Object-to-UI morph（物が UI の部品に化ける）
- コマ：光の板 7.5→ガラスの四角が回る 9.0→ボタンの形に伸びる 9.5→「Publish」の字が入る 10.0→カット 10.11
- Remotion：three.js（@remotion/three）の RoundedBox に transmission の材質→`scale.x` を 1→2.6 に ease-in-out、最後の 3 コマで 2D の Button 部品と入れ替え（同じ位置・同じ角丸）
### 技③ Light-sweep type（光が字を掃いて書く）
- コマ：筋が左から入る 50.3→「Welcome」50.5→「to a whole」51.5→「new Framer」52.0〜52.5 で揃う→54.0 まで保つ
- 字の色＝光の頭の近くは青白・通り過ぎて 0.3 秒で白。字は 1 語ずつ（間隔 0.25〜0.5 秒）
- Remotion：字を `clip-path: inset(0 X% 0 0)` で左から開き、X を光の筋の x と同じ PCHIP で動かす。光の筋＝横長の radial-gradient 2 段（芯 高さ 4px・裾 60px）を screen 合成
### 技④ Background-swap captions（背景の 3D を替えて字だけ差し替える）
- 4 秒ごと（54.15・58.26・62.43）＝曲の 2 小節（120BPM の 8 拍＝4.0 秒）
- 字は中央・白・細め（Framer の書体）・1 語ずつ入る（Design→with→agents）
- Remotion：背景は ガラスの管（three.js の TubeGeometry＋MeshPhysicalMaterial transmission 1・roughness 0.1）をカメラがゆっくり横に流す。字は `<Sequence>` で 4 秒ごと
### 技⑤ Double flash logo（閃光 2 回のロゴ）
- 62.43：L 14→50→64→66（3 コマで山）→0.4 秒で 28（立ち上がり 66ms・落ち 400ms）
- 66.30：L 3→25（1 コマ）→0.63 秒で 1（落ちは expo）＝ロゴが白く飛んで出て、光が引くとロゴの白だけ残る
- Remotion：全画面の radial（中心 = ロゴ）の opacity を `[0,1,0]` を [0, 2f, 2f+12f] で・ロゴは閃光の山のコマで opacity 1・`filter: drop-shadow` 2 段を同じ曲線で落とす
### 技⑥ Shape line collapse（形が横 1 本の線に潰れる）
- 63〜65.5：✦＋C▷ の 4 つが並ぶ→65.5 に高さ 0 の横線（scaleY 1→0.03・ease-in 0.5 秒）→66.3 の閃光でロゴへ
- Remotion：`scaleY` を `EASE.in` で 1→0.03、同時に `filter: blur(0→6px)`・明るさ ×1.4
