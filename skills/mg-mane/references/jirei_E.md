### 効いた事（効いた順）
1. **手本が 30fps→60fps の「混ぜ」か先に見る**：隣の差が2つずつ同じ値（奇数コマの差÷次の差 ≒1）なら奇数コマ＝前後の半々。切り替えの前の奇数コマは止め（差 0）。うちも奇数コマを `<Frame f-1/>` の上に `<g opacity=.5><Frame f+1/></g>`（ぼけの id は React の context で写しごとに名前を分ける）。紙だけの場面は混ぜん方が波が高かった
2. **止めコマは機械で拾う**：`d[i] < 0.2*min(d[i-1],d[i+1])` で 10 コマ（目で拾えたのは 5）
3. **紙の揺れ**：止まって見える紙も 0.1〜0.3px 揺れて網点がちらつく（隣の差 1.0〜1.5）。4隅 256px の位相相関→相似→積み上げ（jitter.py・抜けたコマは前後の一歩の平均で埋める）。×1.6 で差の量が合う（within の波 0.44→0.92）
4. **ぼけは手本の鋭さから1コマずつ解く**（bcal.py）：場面のぼけを 0・1.5・4・10・25 で一律に5回書き出し→コマごとの横・縦の |Sobel| を手本と比べ、対数で内挿して bfix に。網点が先に消えるので1点の式は合わん。FOR の波 0.47→0.92・HEAR 0.80→0.87。手本より絵が素朴な場面（HEART）は 0 に張り付いて下がる＝使う範囲を決める
5. **網点の濃さは FFT の山の強さで合わせる**（手本 6.3＝うちの不透明 0.0187×強さ）。紙の平均は網点で下がるので地を上げる（238）
