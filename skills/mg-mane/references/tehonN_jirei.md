## 効いた技（新しい順）
1. **止まっとるカメラは固定**：ECC で測ったカメラは止まっとる間も ±40px ふらつく＝全部の線が毎コマちらつく（tehonX の UI と同じ）。動く所は生のまま・止まる区間だけ中央値で固定・前後 4 コマでなだらかに。SG で頭や尻まで滑らかにすると、隣の場面のカメラとの受け渡し（217）がずれる
2. **鍵の間は直線**：smoothstep で鍵をつなぐと鍵ごとに速さが 0 になってコマ差が交互に上下する（9→18→11→22）。幅を1コマずつ測って鍵を密に置き、直線でつなぐ
3. **出方は「どこから出るか」を目で決める**：T は上の棒が先に出て茎が下へ伸びる（落ちてくるんやない）・名前の字は床の下から切り抜きで上がる・数字は連続に回る（コマ差が一定なら連続・交互なら2コマおき）
4. **切れ目の前後は生**：地の色の場を時間で滑らかにする時、場面の切れ目をまたぐと段差が出る（420 で一気に橙）→ 切れ目 ±6 コマは生
5. **急に足さん**：窓の床の光・札・枠など、新しい物は手本の出るコマに合わせてフェード（1 コマで足すとコマ差が 2 倍）
6. **テカリ**＝references/tekari.md
7. **音は絵の +0〜30ms 後**：手本の鳴り始めに ±60ms で寄せると絵より先になる音が出る → `min(max(手本, 絵), 絵+30ms)`
