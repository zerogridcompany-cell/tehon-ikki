## 型の名前
- **07 Kinetic type の仲間で、新しい型＝「歌詞の文字PV（Lyric kinetic typography・1語ずつ）」**。waza20 の 07 は「1語が画面いっぱい・板で場面替え・3〜4語で終わる」。こっちは **1語〜1音節ずつ、歌の旋律の音に1つずつ字を乗せ、語ごとに違う出方（打ち込み・落下・せり上がり・回る輪・ばらけ・横流し）を替えていく**。地は無彩の灰3段＋黒で、色は使わん
- 作った道具＝Alight Motion（スマホの MG アプリ）。右上の透かし（Alight Motion の札）は写さん
- 1920x1080・60fps・1309コマ（21.82秒）・-7.2 LUFS（曲がそのまま大きい）

## スキルにまだ無かった技（新しい発見）
1. **字の当て＝字体の輪郭を1コマずつ行列で当てる**（係の tools/fit：Roboto の SVG 輪郭→ECC＋型合わせで語→字の順に 2x3 の行列）。その行列を Remotion の SVG `<path transform="matrix(…)">` にそのまま入れると、打ち込み・落下・伸び・回転・ばらけが全部「手本の数字のまま」動く＝動きの波 0.993・区間 0.981〜1.000。測り値のままでも滑らかさの比 0.87〜1.22（文字PV は止めの間が長く、動きの間はもともと速いので、ギザギザが目立たん）
2. **曲が当たったら同じ曲を落としてサンプル単位で貼る**：YouTube の同じ曲の区間を落とす→メルの形の相関で粗く（0.986。立ち上がりの包絡の相関は別の所に当たって外れた）→波形の相互相関で1サンプルまで（0.975・ずれ 0 サンプル）→手本と同じ LUFS に1つの倍率で。手本の音が曲だけかは「同じ版を窓ごとに引いた残りが一様（-11〜-14dB）か」で見る＝効果音を足すかどうかの決め手
3. **字体の太さの段は「線の太さ÷字の高さ」で当てる**：IoU では Roboto Italic 700 と 900 が同点（0.80）でも、距離変換の 95% から出す太さの比は 手本 0.189・900 0.192・700 0.167 ではっきり分かれる
- ほか：縁だけの字（反転の点滅）は当ての道具が拾えん＝前の見えとるコマの字の行列を持ったまま縁だけで描く／動かん透かしの札は「何も無いコマ」から形を取って伏せる（矩形で伏せると札の切れ端が灰の筋になって残った）／照合の門は透かしを字幕と数える（テロップのコマの割合 1.0）＝透かしを消した手本（delogo）で仕様を作る
