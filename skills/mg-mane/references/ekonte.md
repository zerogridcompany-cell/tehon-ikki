# 台本→絵コンテ→MG（11/3 依頼者「台本を渡してそれに合う MG を作る。ノープランで一気より絵コンテがあった方がいい」・手本＝@heyfraym の Spotify UI「STORYBOARD｜FINAL RENDER」9秒）

手本で見えた事：紙の絵コンテ（鉛筆の荒い絵・1場面1枚・丸と線だけ・字は位置だけ）と完成が左右に並び、**場面が替わるたびに紙もめくれる**＝1場面＝1枚。完成は絵コンテの構図（物の位置・大きさ・字の行）をそのまま守っとる。動きや色は絵コンテに無い（後で決める）。

## 一本道（新作＝手本なし・mg-mane の汎用の型）
1. **台本を句に割る**：1句＝1場面の候補。長さは声で決める（narration で先に録る → jimaku-sync で句の始まり・終わりの秒）
2. **句ごとに「見せ所」を決める**（references/jirei_H.md の言葉→MG の表が土台）：名詞→その物（写真・UI・印）／数→数字の札（回る）／問い→大きい「?」／比べ→左右／並び→3つの丸（手本 72〜87）／手順→リスト（手本 126〜135）／強い1語→赤のセリフ 2倍
3. **絵コンテ＝1句1枚のカード**（`ekonte.json`）：
   ```json
   {"ku":"Global Sound","t":[2.4,3.5],"kousei":"中央に題・下に丸3つ横並び","mono":[{"what":"題","at":"上中","size":"中"},{"what":"丸い札×3","at":"中央","size":"小"}],"ugoki":"丸は左から順に pop（07 Kinetic）・題は打ち込み","waza":[7],"oto":"pop×3・打ち込み tick"}
   ```
   `at` は 9 分割（上左〜下右）で書く・`size` は 大/中/小（画面の高さの 40/20/10%）
4. **下書き板を書き出す**（`scripts/ekonte_board.py ekonte.json ekonte_v0.mp4 [--w 1080 --h 1920 --fps 30] [--voice vo.wav]`＝assets/waza20 の Composition「Ekonte」・11/3 試し＝~/research/tehon-me/ekonte/test/ekonte_v0.mp4）：Remotion で灰色の箱＋ラベルだけの低解像度の動画（色・動き無し・秒は声のまま）。手本と同じく**左＝絵コンテ・右＝（後で）完成**の並びで見せる → 依頼者の OK（ここで構図・順番・秒を直す。本番の後に直さん）
5. 本番＝OK の絵コンテの箱に 20 の技（waza20）・色・音を入れる。構図は絵コンテから動かさん
6. 門＝完成と絵コンテの一致：物の箱の位置の IoU ≥0.7・字の出る秒 ±2コマ（jimaku-sync の秒）・場面の数が同じ。見せる時は左右並び（kurabe と同じ道具で 絵コンテ_v0｜完成）

## 決まり
- 動き（`ugoki`）は easing の役の名前で書く（references/easing.md：出る＝ease out・消える＝ease in・移動＝ease in-out・回る＝linear・味＝overshoot 控えめ）
- 絵コンテは「構図と順番と秒」だけ決める物。色・動き・質感は本番で（手本も鉛筆の丸と線だけ）
- 声が先（ElevenLabs 直 API・11/3 支払い済み）。秒は声から取る＝手で書かん
- 1場面 2〜4秒・1画面に物は 3 つまで（手本は最大 3）
