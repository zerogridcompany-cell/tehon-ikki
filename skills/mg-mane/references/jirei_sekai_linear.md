## 0. 先に結論
1. **55 秒を 1 本のカメラで通す**：カットせず、カメラが UI の上を滑り続けて場面を替える
2. **UI を 3D に寝かせて浅いピントで撮る**：板の傾き約 25°・手前と奥がぼけ、ピントの帯だけ読める＝暗い UI でも「舞台」になる
3. **答えの行は上から 1 行ずつ、ぼけ→くっきり**（行ごとに 0.1〜0.2 秒ずらし）
4. **ロゴはぼけから出て、一瞬だけ色ずれ**（45.5〜46.5）→「. At your command.」が右に足される（主語だけ白・残りは灰）
5. **音はほぼ無音（-32.9 LUFS）**＝静けさで高く見せる型（B 案には使わん・比べの線）

## 2. 技
### 技① One-take UI camera（1 本のカメラで UI の上を滑る）
- カメラの動き＝常に動く（止めん）・速さは 1 秒で画面の 3〜8%・方向を変える時は ease-in-out で 0.5 秒
- Remotion：UI 全体を 1 枚の大きな板（3000px 級）に組み、`perspective` の箱でカメラの `translate3d`・`rotateX/Y` を keys.json の PCHIP で
### 技② Tilted shallow DOF（寝かせた板＋浅いピント）
- 傾き rotateX 約 25°・rotateZ 約 −15°。ピントの帯＝画面の高さの約 30%・外は blur 最大 10px
- Remotion：同じ UI を 3 枚重ねて（くっきり・blur 4・blur 10）、`mask-image` の帯で混ぜる（帯の位置をカメラに合わせて動かす）
### 技③ Row stagger focus-in（行ごとにぼけ→くっきり）
- 1 行 0.1〜0.2 秒ずらし・各行 blur 6→0 と opacity 0→1 を 300ms（ease-out）
### 技④ Blur-in logo with chroma tick（ぼけから出るロゴ＋一瞬の色ずれ）
- blur 12→0 を 0.5 秒（expo-out）・46.5 の 1〜2 コマだけ RGB を ±2px ずらす
- 続く語「. At your command.」は灰（#9a9a9a 付近）で右に opacity 0→1・主語「Linear」だけ白
### 技⑤ Type-on prompt（入力欄に 1 字ずつ）
- 約 8〜10 字/秒・カーソル点滅 530ms
