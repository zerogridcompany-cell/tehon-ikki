## 1回の回し方（1回＝1つ直して測る）
1. **測る**：最新の版がまだ測れてなければ `run.sh render <作業> v<次の番号>`（版は v1, v2… の続き番号。番号を飛ばさん・上書きせん）。書き出しも測りも**同期で待つ**（バックグラウンドにせん＝係が先に終わる）
2. **一番点を失っとる所を出す**：mane_check.json の「判定」と「秒ごと」から、点を一番失っとる **秒と種類**（絵の近さ・カット・動きの波・色・細かい動き・絵が動いとるだけ・字）を1つ決める。手本｜うち｜差の絵（1秒ごと）を作って**自分の目で見て**から決める（数字だけで決めん）
3. **技を選ぶ**：references/waza.md から、その種類に効いた技を選ぶ（例：色→場面ごとの見た目 look・切り替え→cut は最後・中で動く MG→flow_tx か描き分け・字→箱合わせ／書体の当て比べ）。落とし穴は otoshiana.md を先に読む
4. **1つだけ直す**：1回に変えるのは1か所（場面）か1種類。2つ以上変えたらミス帳に「どれが効いたか分からん」と書く
5. **書き出す→測る**：重い作業の前に毎回 `run.sh guard`（止まれと出たら待ってから）。書き出しは必ず `run.sh render`（`--gl=angle`・同時3・土台の組み直しが入っとる）。重い作業は同時1本
6. **振り返る**：前の版と比べ、良くなった数字・悪くなった秒を出す。**悪くなった秒は、新しい直しより先に戻すか直す**。ミス帳.md に1行：`| 版 | 変えた事 | 良くなった | 悪くなった（秒・数字） | なぜ | 次から守る事 |`。同じ所で2回以上悪くなっとる＝同じミス＝原因を1つ決めて道具か決まりにしてから直す
7. **記録**：作り方.md に1行（版・使った技・数字の前→後）。数値の照合.md の一番上に「版・各数字・前の版との差」を1行
8. 1〜7 を続ける。回数の上限は自分では決めん（見張りが点で止める）

## 止める（DONE を書く）
- DONE の1行目は必ず「ゴール到達」か「頭打ち」で始める。2行目以降＝最後の判定（各数字と色）・版の数・見積もりの有無
- **ゴール到達**＝SSIM ≥0.997・カット合う率 ≥99.5%・余計 0・動きの波 ≥0.999・色 ΔE ≤0.1・赤 0（手本を圧縮し直しただけの値＝「完全に同じ」・10/26 依頼者）。51 の数字は途中の段。見張りが数字で確かめる＝数字が届いとらんのに「ゴール到達」と書いても頭打ちとして扱われる
- **頭打ち**＝3回続けて書き出して、どの数字も良くならんかった。その時は 作り方.md に「場面・秒・どの数字・なぜ止まった・何があれば届くか」の表を書いてから DONE

## 頭打ちで止まったら（見張りが起こし直した時）
直し.md の一番下の「再開◯回目」を読んで、**前の回と違うやり方**に変える：
1. 作り方.md の頭打ちの表の「何があれば届くか」のうち、無料でできる物（Codex の絵・描き分け・測り直し・道具づくり・層を分ける）を全部試す
2. 止まった数字ごとに、今までのやり方をミス帳.md から読み、まだ使っとらん技（waza.md）を選ぶ。例：字＝書体を探し直す・1字ずつの層に／切り替え＝余計な切り替えの元の場面を1つずつ消して測る／SSIM＝場面ごとに絵を描き直す
3. 有料が要る所は 見積もり.md に足すだけ（決め.md に許可が無ければ撃たん）

## 決まり
- **字幕・画面の字・数字・UI の字は全部 Remotion で描く**（motion-cm の決まり）。PIL・ffmpeg の drawtext で焼かん
- 絵は Codex で描き直す（`codex exec --skip-git-repo-check -s workspace-write "…"`・`--full-auto` と `-i` は付けん）。手本のコマは下敷きにだけ使う。画素を貼らん
- 手本の音は比べるために敷いてええ（社内の練習用・外に出さん）
- 重さの守り：重い作業の前に `run.sh guard`。ffmpeg は `-threads 2`・`-nostdin`、重い python は `nice -n 10`。待ち合わせに `pgrep -f` を使わん
- 消してええのは自分の作業フォルダの中だけ。古い mp4 は最新と1つ前だけ残す。tmp の remotion-webpack-bundle-* は自分の分を消す
- 落とした動画は区切りで `~/bin/drive-offload --path <作業>/src`
- 手本・ほかの作業フォルダ（51・r2 など）は読むだけ。書かん
- 調べ物は ~/.claude/rules/search-until-found.md の手順（言葉を作り手の名前に直す→手元→YouTube・Web・GitHub・X）。最大15回で「いったん」止めて、探した言葉と場所を作り方.md に書く
