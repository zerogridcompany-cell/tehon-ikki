# 一枚絵を1枚作る（画像生成）

添付の ref.png は動画の1コマ（__W__x__H__）。中身＝__DESC__

この絵と**同じ構図・同じ物の配置と大きさ・同じ色調（__TONE__）・同じ質感と明暗**の絵を、画像生成で1枚作ってほしい。
- 大きさ：見本と同じ縦横比の**標準の大きさ**（横 1536 前後）。🔴高画質・2K・4K にせん（遅くなるだけ・依頼者の決まり「Codex の絵は標準で」）
- 🔴 真ん中に乗っとる白い字幕（英語の短い言葉）は**描かない**。その下の絵を続けて描く
- 絵の一部としてある字は見本どおりの位置と大きさで。実在の人の顔は描かない（人の顔は見本と同じ雰囲気の架空の人に）
- 見本の画素を貼り付け・切り抜き・拡大して使わず、新しく生成した絵にする
- 枠・余白・貼り合わせの縁は作らない（端から端まで全面）

出す物：plate.png（このフォルダ）。使った指示文を prompt.txt に保存。

- 安全判定で拒否されたら（例：拳銃の線画）、同じ場面の別の絵から線を起こす等で代わりを作る。拒否された事は prompt.txt に書く
