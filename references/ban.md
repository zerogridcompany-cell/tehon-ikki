# 板の写し（CapCut）＝字・図・音を CapCut で組んで、手本と重ねて差を0に詰める

🔒 2026-10-31 依頼者「編集はすべて CapCut で。素材だけ持ってきて、ここに字を置いて、このアニメで動かして、ビートを打って、コマを打って」「重ねて薄めて、動きが違ったら違う」「箱に字を入れる時は中心」→ v14 で「マジで素晴らしい・完成度高い。全部スキル化して同じクオリティでいろんな物を」。

対象＝**図・札・題・時計の数字が板（スライド）ごとに切り替わる編集**（TikTok の解説エディット・技術の紹介・インフォグラフィックの曲合わせ）。人や実写が主の手本は本体の一本道（waza.md）。

## CapCut の字の決まり（踏んで分かった事）
- **大きさ**：CapCut は行の高さ（OS/2 の `sTypoAscender − sTypoDescender`）で font_size を決める。1 あたり 11.46px（1920x1080 の下書き）。🔴 hhea の値で計算すると Impact +30%・Selawik +24% 大きく出る
- **位置**：字の箱（送り幅 × typo の行の高さ）の真ん中。墨の真ん中やない（字ごとに PIL で墨と箱の差を出して足す）
- **幅**：横の倍率（clip.scale.x・uniform_scale を切る）で手本の墨の幅に合わせる（0.6〜1.4 に抑える）
- **透明度は素材の `global_alpha`**：clip.alpha と text_alpha は CapCut が開いた時に 1 に戻す。🔴 字に透明度のキーフレーム（KFTypeAlpha）は効かん（動画には効く）。位置のキーフレーム（KFTypePositionX/Y）は字にも効く
- **フェードは測った値を1コマずつ**：字の区切りを1コマずつに割って global_alpha を打つ。CapCut のフェードのアニメ（入り 6724916044072227332・終わり 6724919382104871427・タイプライター 6724920249654710791）は曲がり方が手本と違った（入り2コマ目 手本 0.27／アニメ 0.21）
- **字体**：ttf/otf を下書きの media/ に写して font_path に入れれば CapCut がそのまま読む。🔴 可変の字体（Inconsolata・JetBrains Mono 等）は CapCut が別の太さで描いてずれる（76px）＝固定の字体だけ
- **字体の当て方**：候補で同じ字を書いて、手本の墨と重ねて一番重なる物（高さだけ合わせる＝幅の違いで等幅かどうかが分かる）。手本R＝題 Impact（重なり 0.84・幅の比 1.00）・札 Bahnschrift→D-DIN-PRO・説明 Segoe UI→Selawik・等幅→IBM Plex Mono
- **墨の箱**：一番長い続きの行だけ（下の小さい字の頭を拾わん）。≤ ≥ は STIX Two **Math**（Text には無い）
- 数式・図の中の小さい字（読み違いが多い）は CapCut の字にせず、図の素材の側に残す

## 字の入り方・動き（手本R で測った型＝新しく作る時の既定）
| 動き | 測った値 |
|---|---|
| 板の切り替え | 字も図もそのコマで一斉に替わる（切り込み）。音は絵の約 +23ms 後に鳴る＝**絵を先に切る** |
| 最初の入り | 10コマのフェード：0・0.27・0.49・0.66・0.80・0.89・0.94・0.98・0.99・1.00 |
| 最後の消え | 43コマでほぼ一直線に 1→0 |
| 時計（00.6 s） | 3コマごとに 0.1 進む |
| 札の入れ替え（ITERATION 00→01・02/06→03/06） | 替わるコマで切り込み。左寄せの字は左の端・真ん中寄せは真ん中をそろえる |
| ページ番号 | 「02 / 06」の形（読み違いの「02/06」を直す） |

## 差し替え（同じ動きで別の中身）
cfg の `"replace": {"元の字": "新しい字"}` で、時刻・字体・入り方・図はそのまま、字の中身だけ替える。置き方＝**元の箱の真ん中**（左寄せの字は左の端）・墨の縦の真ん中を箱の真ん中に・箱の幅の 1.1倍を超えたら小さく。図ごと別の中身にするなら、図の素材（zu.mp4）を自分の素材に替えて同じ秒で切る。

## cfg.json（ban/ に置く）
```json
{"name": "下書きの名前", "ref": "手本.mp4", "events": "kouzou_ms.json（events＝板の頭のコマ）か省略で自動",
 "W": 1920, "H": 1080, "fps": 30.0, "audio": "曲.wav（手本と同じ所・同じ速さに合わせた物）", "cover_state": 3,
 "fonts": {"title": "fonts/Impact.ttf", "label": "fonts/D-DIN-PRO-600-SemiBold.otf", "body": "fonts/Selawik-Regular.ttf"},
 "candidates": ["label", "body"],
 "rules": [{"states": [0, 1], "font": "title"}, {"min_h": 40, "max_y0": 260, "font": "title"}],
 "exclude": [[22, "読み違えた字"]], "center_cols": [960], "plain": "caps", "replace": {}}
```
- `rules`：上から順に当たった物で字体を決め打ち（states・text（正規表現）・min_h・max_x0・max_y0・y0・min_w）。当たらん字は candidates から墨の重なりで選ぶ
- `plain`：CapCut の字にする行＝caps（大文字の札・題）・text（英字の行）・all（読めた行全部）
- `k_line`：別の大きさの下書き（縦 1080x1920 等）は、試しの字を1つ書き出して測り直す

## 重ねの門（最後の門）
切り替えのコマと音の ms だけで「合った」と言わん。手本と書き出しを重ねて（半透明＋差分 x4 の並べ動画）、1コマごとの違う画素%・**手本は動くのにうちは止まっとるコマ**・悪い板・字の墨の箱のずれを出し、0に近づくまで直す。手本R v3 は切り替え 75中74 ぴったりでも、手本が動く 294コマ中 195コマで止まっとった。

## 型の下書き（最初に1回）
make_draft_spec.py は自分の CapCut の下書きを型にして組む。CapCut で新しい下書きを作り、動画の段を2つ（下に何か1つ・上に写真を1枚）・字を1つ・音を1つ置いて保存→ CapCut を閉じる→ その下書きのフォルダ（`~/Movies/CapCut/User Data/Projects/com.lveditor.draft/<名前>`）を `~/capcut_tpl` に写す（別の場所なら環境変数 `CK_TPL`）。
字の行の読み取り（ocr_en.swift）は macOS の Vision を使う（初回に swiftc で自動で作る）。字体は付けてない＝手本に近い固定の字体を ban/fonts/ に自分で置く。
